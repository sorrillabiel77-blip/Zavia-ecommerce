ZÁVIA v1.3 — InfinitePay + Render

1. Backup do banco ZÁVIA.
2. Extrair ZIP e enviar TODO conteúdo para repositório GitHub ZÁVIA.
3. Aguardar deploy Render.
4. No app InfinitePay: Vendas > Checkout > Configurações > Habilitar Checkout Integrado; criar API Key.
5. Render > zavia-loja > Environment: INFINITEPAY_TAG e INFINITEPAY_API_KEY (não compartilhe); frete ZAVIA_SHIPPING_FLAT; manter ZAVIA_CHECKOUT_ENABLED=0.
6. Testar checkout/pedidos e configurar logística, produtos reais e expiração de reservas ANTES de ativar vendas.
