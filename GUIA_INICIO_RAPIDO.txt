ZÁVIA FITNESS — COMO SUBIR NO RENDER

ESTE ZIP É UMA LOJA DJANGO / PYTHON, NÃO UM STATIC SITE.

1. EXTRAIR o arquivo ZIP no computador.
2. CRIAR repo GitHub zavia-ecommerce.
3. ENVIAR TODOS os arquivos/pastas extraídos para o REPOSITÓRIO.
4. Conferir que manage.py e render.yaml aparecem na TELA INICIAL do repo.
5. RENDER > New > Blueprint (e não Static Site).
6. CONECTAR repo e autorizar zavia-loja (Web) + zavia-db (Postgres).
7. CONFERIR preço/plano disponível antes de confirmar.
   Para ADMIN: Environment no serviço zavia-loja: ZAVIA_ADMIN_EMAIL e
   ZAVIA_ADMIN_PASSWORD (senha forte, 12+ caracteres), fazer Manual Deploy
   e depois remover estas variáveis.
8. Após deploy, site em https://[nome-real].onrender.com/.
